Addon installieren

1. Lade die ZIP-Datei über die Addon-Karte herunter.

2. Entpacke das Archiv.

3. Kopiere den eigentlichen Addon-Ordner (mit einer .toc-Datei) in den Ordner World of Warcraft/_retail_/Interface/AddOns oder den entsprechenden Ordner deiner WoW-Version.

4. Starte das Spiel neu und aktiviere das Addon im Addon-Menü.

Hinweis

Prüfe, ob das Addon mit der von World of Warcraft Forever verwendeten Spielversion kompatibel ist. Die Download-Dateien werden über GitHub Releases bereitgestellt.
