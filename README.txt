AZEROTHFORGE – WEBSITE (Referenzdesign)

1. ZIP auf dem Gerät entpacken.
2. Alle Dateien und den Ordner assets in das HAUPTVERZEICHNIS von AveAddons/aveaddons.github.io hochladen.
3. Alte index.html, styles.css, app.js, config.js überschreiben.
4. GitHub Pages braucht oft 1–5 Minuten. Browser mit Strg+F5 neu laden.
5. Addons werden automatisch aus AveAddons/addons GitHub Releases geladen. Pro Addon wird nur das neueste Release gezeigt.
6. Für Discord-Einladungslink config.js bearbeiten: discordUrl: "https://discord.gg/DEINLINK". Ohne Link führen die Discord-Buttons nur zum Community-Abschnitt.

Hinweis: Die Hintergrundgrafik ist eine bildliche Annäherung an das Referenzdesign; echte Texte und Buttons werden separat im HTML gerendert.
