AZEROTHFORGE – WEBSITE
=======================
Dateien aus diesem Ordner direkt ins Stammverzeichnis von
https://github.com/AveAddons/aveaddons.github.io hochladen.
Wichtig: assets/ inklusive aller Unterordner mit hochladen.

GitHub-Releases: https://github.com/AveAddons/addons/releases
Die Addon-Karten werden automatisch aus den echten Releases geladen.
Die drei Beispiel-Addons aus dem Designbild sind keine echten Releases.
Discord: Einladungslink in config.js unter discordUrl eintragen.
Diese Version ist eine möglichst nahe Web-Umsetzung des Referenzdesigns;
das Hintergrundmotiv basiert auf den verfügbaren Bilddateien und ist
nicht pixelidentisch mit der Illustration.
