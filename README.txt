AZEROTHFORGE – KOMPLETTPAKET (11.10.2026)

Enthalten: index.html, styles.css, app.js, config.js und sämtliche Bilddateien im Ordner assets/.

GitHub Pages Installation:
1. ZIP auf dem Gerät entpacken.
2. Im GitHub Repository der Website ALLE enthaltenen Dateien und den Ordner assets/ hochladen bzw. vorhandene ersetzen.
3. Die Ordnerstruktur muss erhalten bleiben: assets/hero-v2.jpg, assets/community-v2.jpg und assets/addons/*.png.
4. Nach Veröffentlichung Seite neu laden, ggf. Browser-Cache leeren.

Addon-Daten werden automatisch aus den öffentlichen GitHub Releases von AveAddons/addons geladen.
Downloads funktionieren nur, wenn die Releases echte .zip-Dateien als Release Assets besitzen.
Discord-Link optional in config.js ergänzen. Solange leer, zeigen Discord-Schaltflächen nur auf den Community-Abschnitt.
