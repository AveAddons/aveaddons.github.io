AZEROTHFORGE – KOMPLETTPAKET

INSTALLATION:
1. ZIP herunterladen und entpacken.
2. ALLE enthaltenen Dateien und den Ordner assets in das Hauptverzeichnis
   des GitHub-Repositories AveAddons/aveaddons.github.io hochladen.
3. Vorhandene Dateien ersetzen. Die Ordnerstruktur unverändert lassen.
4. NICHT die ZIP selbst als einzige Datei ins Repository hochladen.
5. Nach dem GitHub-Pages-Deployment die Website neu laden.

Die Addon-Liste lädt GitHub Releases aus AveAddons/addons.
Downloads benötigen ein ZIP-Asset in der jeweiligen GitHub Release.
Optional: discordUrl in config.js setzen.
