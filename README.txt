AZEROTHFORGE – REFERENZLAYOUT (3 SPALTEN)

Dieses Paket enthält alle Dateien der Website, inklusive Bilder,
GitHub-Releases-Anzeige, Suche und Download-Schaltflächen.

WICHTIG: Wie im Referenzbild sind auf Desktop drei gleich breite
Spalten vorgesehen. Solange nur zwei Addons veröffentlicht sind,
bleibt die dritte Spalte leer. Es werden keine Demo-Addons erfunden.

INSTALLATION:
1. ZIP herunterladen und entpacken.
2. Alle entpackten Dateien und den Ordner assets in das Hauptverzeichnis
   von https://github.com/AveAddons/aveaddons.github.io hochladen.
3. Bestehende Dateien mit gleichem Namen ersetzen.
4. Änderungen committen und auf GitHub Pages Deployment warten.
5. https://aveaddons.github.io/ neu laden (ggf. Browser-Cache leeren).

ZIP-Dateien für Addon-Downloads werden aus den Release-Assets des
Repositories AveAddons/addons übernommen.
